## This is where it all begins.

My first time as a game programmer. Thought it would be no hassle,
but actually it was quite troublesome as you have to do code while maintain good communication between team members.

I won't say it was a successful game, not even proud of it,
but this is where i realize that there are more than just doing code as a programmer.

I worked on this with the help of my highschool friends as a team, to face a game developing competition.
The game designer was [Hanif](https://hanifnaoh.github.io), who did all the work on making the game fun.
Zeeo, an artist, which do all the heavy work on the art.
Azfa, level designer, which designs the map of the world.
